Please note that when you make a Eaglercraft client, after a few months it would be **taken down.** GitHub had **sweeped 1,357** repostories in 2026. This is because that **both Microsoft and Mojang** wanted to **protect their property** from copycats.


## Why DMCAs happen

DMCA (Digital Millennium Copyright Act) takedowns happen when copyright owners find their intellectual property (like videos, music, code, or images) being shared or used without permission online. The law gives creators a fast, legal way to demand that websites and platforms remove the infringing content.

## Does Eaglercraft cause DMCAs?

Yes. This is not a **clone**. This is an actual **copy of Minecraft Java Edition**. I know it uses older versions like **1.8.8** or **1.5.2**. **However, when it became popular, Microsoft forced a DMCA and a copyright violation to the main creator **lax1dude**, because they assumed it is a copy.**
